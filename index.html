College Placement Data Analysis and Prediction

Built a machine learning pipeline to preprocess college placement data and predict placement outcomes using a Random Forest classifier.

  • Cleaned column names, removed duplicate records, and handled missing numerical and categorical values using median and mode imputation.
  • Encoded categorical features using LabelEncoder and standardized numerical features using StandardScaler before model training.
  • Split the dataset into training and testing sets and evaluated predictions using accuracy, confusion matrix, and classification report.
  • Serialized the trained model, label encoders, and scaler using Joblib for reuse in future prediction workflows.
